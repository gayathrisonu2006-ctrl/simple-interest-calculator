# Simple Interest Calculator

## Description
The Simple Interest Calculator is a simple Python-based project used to calculate the interest on a principal amount for a given rate and time period.

## Objective
To calculate simple interest easily and quickly using a mathematical formula.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Total Amount = Principal + Simple Interest

## Input
- Principal Amount
- Rate of Interest
- Time Period

## Output
- Simple Interest
- Total Amount

## Example
Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

Total Amount = 1000 + 100 = 1100
